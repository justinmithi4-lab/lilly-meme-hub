# PayChangu checkout setup

Membership purchases use PayChangu Standard Checkout. Customers complete a
one-time payment on PayChangu's hosted checkout page; the server verifies each
transaction before activating the membership.
The existing manual Airtel Money and TNM Mpamba submission options remain
available as alternatives.

1. Set `APP_URL` to the public base URL of the app. PayChangu must be able to
   reach this URL; use HTTPS in production.
2. Add the PayChangu API secret key as `PAYCHANGU_SECRET_KEY`.
3. In the PayChangu dashboard, configure the webhook URL as
   `{APP_URL}/api/payments/paychangu/webhook` and add its webhook secret as
   `PAYCHANGU_WEBHOOK_SECRET`.
4. Run the app's database migrations with `npm run migrate`.
5. Start with PayChangu test credentials, then switch to live credentials after
   verifying successful, cancelled, and failed checkout flows.

The checkout callback URL is generated by the app. The webhook is validated
with PayChangu's SHA-256 HMAC signature and transactions are re-verified using
the PayChangu verification API before any membership is activated. Do not expose
either PayChangu secret key in browser code.
